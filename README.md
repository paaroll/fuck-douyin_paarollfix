# 抖音净化 paaroll 修复版

基于 [wan-kong/fuck-douyin](https://github.com/wan-kong/fuck-douyin) 的独立维护分支，主要改善抖音网页版直播间的送礼栏屏蔽和副屏观看体验，保留上游的视频净化功能。

维护仓库：[paaroll/fuck-douyin_paarollfix](https://github.com/paaroll/fuck-douyin_paarollfix) 。原作者为 wan-kong，本分支修复由 paaroll 维护，与抖音官方无关联。

## 本分支的改进

| 功能 | 实际行为 |
| --- | --- |
| 屏蔽底部送礼栏 | 普通和全屏播放均持续隐藏，覆盖礼物栏搬入播放控制区和动态重建的情况。 |
| 失焦时隐藏控制栏 | 在其他窗口工作时，副屏直播底部菜单保持隐藏；点击切回直播窗口后恢复网页原有控制行为。 |
| 暂停后台自动操作 | 失焦隐藏开启时，脚本不模拟鼠标或点击，也不自动操作画质；切回后继续尚未完成的配置。 |
| 即时开关 | 送礼栏和失焦控制栏可以分别开关，总开关关闭时解除隐藏。 |

送礼栏屏蔽和失焦隐藏默认开启。视频、声音和画面布局由原播放器继续管理；窗口激活时，播放、音量、画质、全屏和多机位等控件保留。

本分支同时保留上游的自动跳过广告、直播卡片、购物内容，自动选择最高画质，隐藏页面区域和播放器侧边按钮，以及直播礼物动画、弹幕和信息标签等设置。

## 安装

需要支持油猴脚本的浏览器扩展，例如 [Tampermonkey](https://www.tampermonkey.net/) 。

### 从构建文件安装

1. 用文本编辑器打开本分支生成的 `douyin-paarollfix.user.js`，复制全部内容。
2. 在脚本管理器中选择「新建脚本」，全选替换默认内容并保存。
3. 打开或刷新[抖音网页版](https://www.douyin.com/) 或[独立直播间](https://live.douyin.com/) 。
4. 点击右下角「净」按钮，在「直播」中检查「屏蔽底部送礼栏」和「失焦时隐藏控制栏」。

当前构建关闭脚本自动更新；升级时，在同一份本分支脚本的编辑器中替换为新构建内容，设置会继续保留。原作者的 Greasy Fork 发布页属于上游，不是本分支的安装入口。

### 从源码构建

使用 Node.js 22.12 或更高版本，以及 pnpm。在项目目录执行：

```bash
pnpm install --frozen-lockfile
pnpm build
```

构建生成 `dist/douyin-paarollfix.user.js`，按上面的步骤安装即可。脚本使用 CDN 加载 Vue，运行时需要能够访问对应资源。

## 从原版或本地修订版迁移

本分支使用自己的脚本名称和 namespace，脚本管理器会将其与上游、本地修订版分别管理。

1. 先禁用原版或原来的本地修订版，避免两份脚本同时处理页面。
2. 安装「抖音净化 paaroll 修复版」。
3. 刷新抖音页面，重新核对功能开关。

其他脚本的 GM 存储不会自动迁入本分支。本分支内部仍使用 `fd_config` 和 `fd_fab_pos` 保存配置与按钮位置，后续更新会合并新默认值，保留已有选择。

## 副屏观看方法

将独立直播间放在副屏，开启「失焦时隐藏控制栏」，再切到主屏的其他窗口工作。直播仍可见时，窗口也可能已经失去焦点；脚本按焦点状态隐藏底栏，不会因为副屏还在显示画面就持续弹出菜单。

只把鼠标移回直播窗口而不激活它时，底栏仍会隐藏。需要调整音量、画质或多机位时，点击直播窗口或用 `Alt+Tab` 切回，再操作控件。想恢复网页原来的悬停菜单行为，关闭「失焦时隐藏控制栏」即可，送礼栏屏蔽不受影响。

本次直播修复作用于 `live.douyin.com` 独立直播间；短视频信息流保持上游功能。

## 配置与数据

配置优先保存在脚本管理器的本地存储中；开发环境没有 GM API 时回退到 localStorage。脚本没有主动采集或上传用户数据的逻辑；它会加载 Vue、图标和字体等外部资源。

抖音网页结构变化可能影响选择器或自动设置。出现异常时，可以先关闭对应功能定位；描述问题时请提供页面地址、浏览器与脚本版本、已开启的选项，以及触发步骤，不要附上 Cookie 或账号凭据。

## 开发和检查

```bash
pnpm dev       # 启动脚本开发服务器
pnpm build     # 严格类型检查并构建用户脚本
pnpm test      # 重新构建，再运行浏览器与发布信息检查
```

第一次使用默认测试浏览器时，执行：

```bash
pnpm exec playwright install chromium
pnpm test
```

也可以使用已安装的 Google Chrome，避免下载测试浏览器。在 PowerShell 中执行：

```powershell
$env:PLAYWRIGHT_CHANNEL = 'chrome'
pnpm test
```

测试加载构建后的完整用户脚本，使用本地页面夹具，不访问真实抖音。焦点相关用例明确模拟焦点信号，覆盖失焦隐藏、切回恢复、异步设置中途失焦、动态重建、开关和旧配置；它们不等同于实际物理双屏操作。

工程约定见 `AGENTS.md`，当前进度和验证记录见 `ROADMAP.md`。只修改源码，不手工编辑 `dist/` 中的生成文件。
